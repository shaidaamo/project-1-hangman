## Description
The Hangman Game Is A Game That's Make You Guess A Word. You Have A Hint, You Guess The Letters Of This Word, While Having The Count Of These Letters. You Have Six Chances Until The Hangman Gets His Body Drawn. Also, You Have 60 Seconds To Guess The Word. You Can Pause And Resume, And Restart If You End Up Losing.

## User Stories
1. As A User I Want To Be Able To Choose Letters.
2. As A User I Want To See How Many Chances I Do Have.
3. As A User I Want To See The Hangman And How He Changes If I Made A Mistake.
4. As A User I Want A Restart Button.
5. As A User I Want To See The Word I Am Trying To Guess.
6. As A User I Want To See Which Letters I Already Did Choose.
